# 桐桐貓貓島

桐桐自己畫設計圖的 3D 貓貓島。島上住著 50 隻貓，每天比跳高，還會表演、寫日記、寫數學作業。

網址：https://tong.xjack.tw

## 島是怎麼來的

桐桐拿鉛筆畫了一張自己的島：中間是貓貓之家，旁邊有高、中、低三座跳臺，還有公園和頒獎臺。後來她又在同一張紙上加了表演區、多多紙箱區、日記區、合體公園和貓貓教練，最後又說要一座學習數學島。

島的形狀、位置和木板橋，都照她的設計圖做。

## 怎麼玩

- 跳臺：按住大按鈕蓄力，放開就跳。能量條碰到黃色那一段放開，貓會在空中翻跟斗。
- 表演區：叫臺上的貓轉圈圈、揮手、翻跟斗、唱歌，也可以按拍手。
- 日記區：看貓把今天做的事寫成日記，幫牠蓋貓掌印，或按「唸給我聽」。
- 學習數學島：點黑板，戴眼鏡的貓貓老師會上課，教一年級上學期的 9 個單元。點老師或講台就改作業：每天有 10 隻貓來上課、各寫一張，你當老師改「寫對了」還是「寫錯了」，改錯了老師會提醒你。
- 日記區和學習數學島的字都有注音。

成績和日記只存在你自己的瀏覽器裡，換一台裝置會從頭開始。網站用 Google Analytics 統計瀏覽次數和大家喜歡玩什麼（例如打開哪座島、改了第幾單元的作業），不會收集名字之類的個人資料。
